# lookataslam website

Author site for Mohammad Aslam — built with vanilla HTML/CSS/JS.

## Local preview
Just open `index.html` in any browser.

## Deploy to Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. From this folder: `vercel`
3. Set project name to `lookataslam` → it will deploy to `lookataslam.vercel.app`

## Add your cover image
Put the cover art file as `assets/cover.jpg` and it will show automatically.

## Structure
```
website/
  index.html   — main page
  style.css    — all claymorphism styles
  script.js    — scroll animations + nav
  vercel.json  — deployment config
  assets/      — put cover.jpg here
```
